# Участник 4 — администратор

Файлы: admin.py, templates/admin.html. Форма статуса находится в templates/order_detail.html.
Права проверяются admin_required из security.py. Допустимые переходы — catalog.py.

Логин admin, пароль admin. Аккаунт создаётся автоматически при первом запуске.
Сайт по умолчанию слушает только 127.0.0.1: учебный пароль не предназначен для публичного сервера.
Для новой БД можно задать ADMIN_PASSWORD до запуска; существующий пароль переменная не перезаписывает.

В /admin:
- все заказы всех пользователей, покупатели, суммы и способ получения;
- фильтр по статусу и количество заказов;
- переход к составу и форме смены статуса.

Доставка: accepted → cooking → ready → on_way → delivered.
Самовывоз: accepted → cooking → ready → delivered.
Отменить можно любой незавершённый заказ. Завершённый и отменённый — финальные.
Пропускать шаги и возвращаться назад нельзя.
previous_status защищает от одновременного редактирования в двух вкладках: устаревшая форма получает 409.
UPDATE и запись события выполняются в одной транзакции.

Показать: полный цикл доставки, выдачу самовывоза, отмену и отказ /admin для покупателя.
