# Участник 5 — карта, оформление, документация и проверка

Файлы: templates/contacts.html, templates/base.html, static/css/style.css, README.md, START_HERE.md, tests/test_app.py.
Новые шаблоны оформлены в том же стиле, что исходные пять страниц.

Карта:
- Google Maps встроена через iframe с адресом: Санкт-Петербург, Будапештская улица, 38.
- Подпись «Пять сыров — условная точка» находится на сайте; сама карта ищет указанный адрес.
- Реальная карточка компании в Google не создаётся.
- Для другого места измените PIZZERIA_ADDRESS в location.py. Адрес автоматически обновится в контактах, карте и новых заказах самовывоза.
- Нужен интернет. Если iframe блокируется браузером/сетью, есть ссылка «открыть точку в Google Maps».
- Возможность работы внешней карты зависит от Google; основной сайт и заказы работают без неё.

Проверка:
1. Распаковать в новую папку, создать новое окружение и установить requirements.txt.
2. Запустить команды из START_HERE, пройти полный сценарий.
3. Выполнить:
   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
4. Проверить узкое окно: меню, формы, корзину и карточку заказа.
5. Проверить неверную почту, дубли почты, защищённые страницы, цены и статусы.
6. Обновить README только реальными результатами. Не загружать instance и .venv в Git.

Автотесты создают временную БД; пользовательские заказы не удаляются.
