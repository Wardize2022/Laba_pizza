Лабораторная работа № 1 по дисциплине «Технологии разработки программного обеспечения».
Назначение: представить меню, акции, условия доставки и контакты вымышленной пиццерии.
Планируется пять самостоятельных страниц. Сейчас добавлен каркас, личные страницы ещё не реализованы. Приём заказов и онлайн-оплата не реализованы.

## Запуск в Windows PowerShell

Откройте терминал в папке, где лежит `app.py`. Команды выполняются по одной:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Если `py` не найден, но `python --version` показывает Python 3.10+, в первой команде замените `py` на `python`.

## Запуск в macOS/Linux

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python app.py
```

Открыть в браузере: http://127.0.0.1:5000/ . Остановить сервер: Ctrl+C в терминале.
Активация окружения не требуется: команды явно используют его Python.
Для повторного запуска достаточно последней команды. После изменения Python-кода остановите и запустите сервер снова.

## Как устроен код

`app.py` создаёт приложение и вызывает `register_routes(app)` из `routes.py`.
Внутри этой функции зарезервированы пять блоков для личных обработчиков; пока в них стоит `pass`.
Каждый обработчик возвращает свой шаблон через `render_template()`.
Шаблоны наследуют общую HTML-оболочку `base.html`: шапку, навигацию и подвал.
CSS хранится в `static/css/style.css`.
