# Пять сыров — учебная пиццерия на Flask

Продолжение группового проекта: исходные пять страниц дополнены регистрацией,
корзиной, заказами, историей статусов и панелью администратора.
Все заказы демонстрационные: без реальной оплаты, отправки в ресторан и доставки.

## Запуск

Python 3.10+, Flask 3.1.3, SQLite из стандартной библиотеки Python.
Не нужен отдельный сервер БД, почтовый сервис или платёжный сервис.

Windows PowerShell, в папке с app.py:
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

macOS/Linux:
```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python app.py
```

Открыть http://127.0.0.1:5000/ . Остановка — Ctrl+C.
После изменения Python-кода сервер нужно перезапустить.
Если порт занят: `python -m flask --app app run --port 5005` через Python вашего окружения.

## Учётные записи

- Покупатель создаётся на /register, входит по почте и паролю на /login.
- Учебный администратор: **логин admin, пароль admin**.
- Пароли в БД хешируются с помощью Werkzeug/scrypt.
- При первом запуске создаются `instance/pizza.sqlite3` и локальный `instance/secret.key`.
- Перезапуск не стирает пользователей и заказы. Эти файлы исключены из Git.
- Перед переносом данных сохраните копию instance при остановленном сервере.
- Для проверки двух ролей одновременно используйте обычное и приватное окно браузера.
- Все аккаунты, открывающие один работающий сервер, используют одну БД. Разные распакованные копии имеют разные БД.

Пароль admin/admin предназначен для локальной защиты работы. Приложение слушает 127.0.0.1.
Перед публичным использованием нужно отдельно подготовить развёртывание, HTTPS и настройки безопасности.
Переменная окружения ADMIN_PASSWORD задаёт пароль только при создании администратора в новой БД.
SECRET_KEY можно задать переменной окружения; иначе генерируется локальный секрет.

## Проверка ввода

Почта нормализуется в нижний регистр, краевые пробелы убираются.
До 254 символов всего и до 64 перед @; латинский адрес с доменом и точкой.
Не принимаются внутренние пробелы, управляющие символы, двойные точки до @,
пустые доменные метки, метки с дефисом по краям и домен без зоны.
Допустимы распространённые символы локальной части, включая + и подчёркивание.
Это учебная политика для ASCII-адресов, а не поддержка всех вариантов RFC/международных адресов.
Повторная регистрация с той же почтой, включая другой регистр, запрещена.

**Это проверка формата и уникальности, не подтверждение владения почтой. Письма не отправляются.**

Имя: 2–60 символов; пароль: 8–128 символов, повтор пароля обязателен.
Телефон заказа: 10–15 цифр с допустимыми разделителями; адрес доставки: 10–250 символов;
комментарий: до 500. Проверки выполняются на сервере, даже если обойти HTML-ограничения.
После 5 неудачных попыток входа сочетание IP/логина блокируется до конца минутного окна.

## Корзина, цены и акции

- Корзина хранит ID и количество; цены сервер берёт из catalog.py.
- Оформление доступно только после входа. Корзина гостя сохраняется при входе.
- От 1 до 20 пицц каждого вида; 0 в форме изменения количества удаляет позицию.
- Самовывоз: скидка 10%. Три и более пицц с доставкой: скидка 10%.
- Скидки не суммируются. Обеденная акция относится к заказам в зале и онлайн не применяется.
- Доставка: от 500 ₽ после скидок; до 1000 ₽ стоимость 150 ₽; от 1000 ₽ бесплатно.
- Суммы хранятся целыми копейками; в заказ сохраняются снимки названий и цен.
- Повторная отправка той же формы не создаёт второй заказ.
- Заказ, его позиции и первый статус сохраняются одной транзакцией.
- При выходе очищаются сессия и корзина, но заказы остаются в БД.

## Заказы и статусы

Покупатель видит только свои заказы. Администратор видит все, может фильтровать их и менять статус.

Доставка:
`Принят → Готовится → Передан в доставку → Курьер в пути → Доставлен`.

Самовывоз:
`Принят → Готовится → Готов к выдаче → Выдан`.

Любой незавершённый заказ можно отменить. Завершённые и отменённые заказы не редактируются.
Обратные переходы и пропуск шагов отклоняются. Устаревшая форма администратора возвращает 409.
Каждый переход записывается в историю с временем UTC.
Активная карточка покупателя обновляется раз в 15 секунд; это отслеживание статуса, не GPS курьера.

## Карта

Google Maps встроена на /contacts через iframe. Адрес: Санкт-Петербург, Будапештская улица, 38.
Подпись «Пять сыров — условная точка» размещена на сайте, сама карта ищет указанный адрес.
По этому месту нет настоящей пиццерии проекта; карточка вымышленного бизнеса в Google не создаётся.
Для карты нужен интернет; есть запасная ссылка открытия точки в Google Maps.
Вариант iframe не требует внесения ключа в проект. Доступность зависит от Google, сети и настроек браузера.
Чтобы изменить место, поменяйте PIZZERIA_ADDRESS в location.py: контакты, карта и новые заказы самовывоза используют один адрес.

## Файлы

| Файл | Назначение |
|---|---|
| app.py | Создание Flask, конфигурация, подключение модулей |
| routes.py | Исходные пять информационных страниц |
| database.py, schema.sql | Подключение SQLite и создание таблиц |
| security.py | Сессия пользователя, проверка роли, CSRF |
| auth.py | Регистрация, вход, выход, проверка почты |
| catalog.py | Пиццы, цены и общие правила статусов |
| location.py | Единый адрес для карты, контактов и самовывоза |
| shop.py | Корзина, расчёт и оформление |
| orders.py | Заказы пользователя и детали |
| admin.py | Список всех заказов и смена статусов |
| templates/ | Jinja-шаблоны, общая оболочка base.html |
| static/css/style.css | Общее адаптивное оформление |
| tests/test_app.py | Автоматические проверки |
| guides_next/ | Инструкции пяти участникам |

Основные таблицы: users, orders, order_items, order_events, login_attempts.
SQL-запросы используют параметры. Проверка прав выполняется сервером.
Все изменяющие действия — POST с CSRF-токеном, а пользовательский текст экранируется шаблонами.

## Маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | /, /menu, /promotions, /delivery, /contacts | Исходные страницы |
| GET, POST | /register, /login | Регистрация и вход |
| POST | /logout | Выход |
| POST | /cart/add/<id> | Добавить пиццу |
| GET, POST | /cart | Корзина и изменение количества |
| GET, POST | /checkout | Оформление заказа |
| GET | /orders, /orders/<id> | Мои заказы и детали |
| GET | /admin | Все заказы (только администратор) |
| POST | /admin/orders/<id>/status | Смена статуса (только администратор) |
